## 二、你还必须配置的 5 项环境变量（在 `backend/.env`）

| 变量 | 当前值 | 去哪拿 |
|---|---|---|
| `WECHAT_MCH_ID` | `xxxx`（占位） | 微信支付商户平台 → 顶部「我的商户号」（纯数字） |
| `WECHAT_PAY_API_V3_KEY` | `xxxx...`（占位） | 商户平台 →「账户中心」→「API安全」→「APIv3密钥」→ 设置/查看 |
| `WECHAT_PAY_SERIAL_NO` | `xxxx`（占位） | 商户平台 →「API安全」→「API证书」→ 证书序列号（API证书详情里） |
| `WECHAT_PAY_NOTIFY_URL` | `https://your-domain.com/...`（占位） | 改成你**服务器公网 HTTPS 域名** + `/api/pay/notify` |
| `WECHAT_PAY_REFUND_NOTIFY_URL` | 同占位 | 改成公网 HTTPS 域名 + `/api/pay/refund/notify`（可先复用 notify 的域名） |

> `WECHAT_APP_ID` 已正确（`wx005066bc50bb8957`），**必须与商户号在微信支付后台绑定的 AppID 完全一致**。

## 三、还必须放 2 个证书文件（在 `backend/cert/`）

| 文件 | 用途 | 获取方式 |
|---|---|---|
| `apiclient_key.pem` | 商户 API 私钥（用于请求签名 + 回调验签） | 商户平台 →「API安全」→「API证书」→ 下载证书工具生成后解压得到 |
| `wechatpay_platform.pem` | 微信支付平台证书（用于验证回调签名） | 用微信官方 **证书下载工具** 获取（不是手动拼的） |

放置后，确认 `.env` 中指向它们：
```
WECHAT_PAY_PRIVATE_KEY_PATH=./cert/apiclient_key.pem
WECHAT_PAY_PLATFORM_CERT_PATH=./cert/wechatpay_platform.pem
```
（也可直接把证书文本填进 `WECHAT_PAY_PRIVATE_KEY` / `WECHAT_PAY_PLATFORM_CERT`，换行写成 `\n`。）

⚠️ 这两个文件是核心敏感凭据，**不要提交到 git / 公开仓库**（`cert/` 已被 .gitignore 忽略）。

## 四、环境要求（很多人卡在这）

1. **公网 HTTPS 回调地址**：微信支付回调（`/api/pay/notify`）必须是**公网可达的 HTTPS** 地址，且证书有效。
   - 本地 `localhost` / 内网 IP 收不到回调 → 支付会一直显示「支付中」无法到账。
   - 部署到已有的生产网关（如 `zych.net.cn`，项目当前已用）即可，改成 `https://zych.net.cn/api/pay/notify`。
2. **AppID 与商户号绑定**：商户平台 →「产品中心」→「AppID账号管理」中，确认已关联本小程序 AppID。
3. **金额单位**：代码里统一用「分」，`.env` 无需配置；`actual_price`/`quote_price` 以「元」存，下单时自动 ×100。
4. **合法域名**：小程序后台「开发设置 → 服务器域名」的 request 合法域名需包含你的网关域名（开发者工具可勾选「不校验合法域名」调试）。

## 五、配置完成后如何验证

1. 启动后端，运行自检（不打印任何密钥明文）：
   ```bash
   cd backend
   node check_pay_config.js
   ```
   全部 ✅ 即代表凭据/证书齐全。

2. 重启后端服务（env 与证书改动需重启 Node 才生效）。

3. 真机/工具内走一遍：用户接受报价 → 订单详情点「去支付」→ `wx.requestPayment` 拉起收银台 → 支付成功 → 微信回调 `/api/pay/notify` → 订单 `payment_status` 变 `paid`。

4. 若回调收不到：检查服务器公网 HTTPS 是否通、路径是否为 `/api/pay/notify`、防火墙/网关是否放行 POST。

---

## 六、一句话总结

> 代码已就绪，**你只需要**：① 填 `backend/.env` 里 4 个商户凭据 + 1 个回调域名；② 把两个 `.pem` 证书放进 `backend/cert/`；③ 保证回调地址是公网 HTTPS；④ 重启后端跑 `node check_pay_config.js` 全绿即可上线。
