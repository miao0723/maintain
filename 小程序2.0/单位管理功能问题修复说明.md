# 单位管理功能问题修复说明

## 问题描述

用户反馈：在单位管理页面添加完单位后，返回订单页面，单位信息没有刷新显示。

## 问题分析

1. **页面生命周期问题**
   - 单位编辑页面保存成功后直接 `navigateBack()` 返回
   - 维修订单页面的 `onShow()` 生命周期没有正确触发
   - 导致 `loadUnitList()` 方法没有被调用

2. **数据同步问题**
   - 单位信息保存在本地存储 `wx.setStorageSync('units', units)`
   - 但订单页面没有从最新的存储中读取数据
   - 旧的 `unitList` 数据还在页面状态中

## 解决方案

### 1. 添加 onReady 生命周期

**文件：** `pages/repair/repair.js`

在维修页面添加 `onReady()` 生命周期钩子，确保页面准备就绪时加载单位列表：

```javascript
onReady() {
  console. log('维修页面准备就绪');
  // 页面准备就绪时也加载单位列表，确保数据最新
  this.loadUnitList();
},
```

### 2. 优化 loadUnitList 方法

**文件：** `pages/repair/repair.js`

添加详细的日志输出，方便调试：

```javascript
loadUnitList() {
  const app = getApp();
  if (!app.globalData.isLoggedIn) {
    return;
  }

  console.log('开始加载单位列表...');

  const { unitApi } = require('../../utils/api.js');
  unitApi.getUnitList()
    .then(units => {
      console.log('API返回单位数据:', units);
      
      // 处理数据格式并设置默认单位
      // ...
    })
    .catch(err => {
      console.error('加载单位列表失败:', err);
      // 回退到本地存储
      const units = wx.getStorageSync('units') || [];
      console.log('从本地存储加载单位:', units);
      // ...
    });
}
```

### 3. 修改单位编辑页面的保存逻辑

**文件：** `pages/unit-edit/unit-edit.js`

在保存成功后，主动通知上一页刷新单位列表：

```javascript
// 通知上一页刷新单位列表
const pages = getCurrentPages();
console.log('当前页面栈长度:', pages.length);

if (pages.length >= 2) {
  const prevPage = pages[pages.length - 2];
  console.log('上一页:', prevPage);

  // 检查上一页是否有 loadUnitList 方法
  if (prevPage.loadUnitList && typeof prevPage.loadUnitList === 'function') {
    console.log('调用上一页的 loadUnitList 方法');
    setTimeout(() => {
      prevPage.loadUnitList()
    }, 100);
  } else {
    console.log('上一页没有 loadUnitList 方法');
  }
}
```

### 4. 添加单位列表页面的日志

**文件：** `pages/units/units.js`

添加日志输出，便于追踪数据加载：

```javascript
loadUnits() {
  // ...
  
  if (useLocalStorage) {

    this.setData({
      unitList: units
    });
  } else {
    // 使用API
    unitApi.getUnitList()
      .then(units => {
        console.log('从API加载单位列表:', units);
        // ...
      })
  }
}
```

## 注意事项

1. **调试方法**
   - 打开微信开发者工具的控制台
   - 查看日志输出，追踪数据加载过程
   - 特别关注 `loadUnitList` 方法的调用

2. **本地存储模式**
   - 当前使用 `useLocalStorage = true` 模式
   - 单位数据存储在 `wx.getStorageSync('units')`
   - 可以在控制台的 Storage 面板中查看存储数据

3. **默认单位逻辑**
   - 用户只能有一个默认单位
   - 设置新单位为默认时，取消其他单位的默认状态
   - 如果没有默认单位，订单页面不会自动选择

## 后续优化建议

1. **使用全局事件通知**
   - 在 `app.js` 中实现全局事件监听机制
   - 单位保存后触发事件，所有订阅的页面自动刷新

2. **使用小程序全局数据**
   - 将单位列表存储在 `app.globalData` 中
   - 所有页面共享同一份数据

3. **添加数据持久化**
   - 后端API完成后，同步到本地存储
   - 确保离线和在线模式数据一致
