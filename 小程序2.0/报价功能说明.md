# 管理员报价和用户确认功能说明

## 功能概述
- 管理员可以给维修中（processing）的订单返回报价
- 管理员可以上传报价报告文件（支持图片和文档）
- 用户可以看到管理员的报价详情和报告文件
- 用户可以接受或拒绝报价

## 数据库迁移
运行以下SQL文件来添加必要的字段：
```bash
mysql -u root -p repair < backend/database/migrations/20260425_add_order_quote_fields.sql
```

## 使用流程

### 管理员操作
1. 进入"我的订单"页面
2. 点击"维修中"状态下的订单
3. 在订单详情中点击"返回报价"按钮（仅处理中的订单显示）
4. 填写报价金额（必填）
5. 填写报价说明（选填）
6. 上传报告文件（选填，支持多选）
   - 支持图片格式：jpg, png, gif, webp
   - 支持文档格式：pdf, doc, docx, xls, xlsx, txt
7. 点击"提交报价"

### 用户操作
1. 在"我的订单"页面点击订单
2. 在订单详情中查看报价信息
3. 如果报价状态为"待确认"，可以看到：
   - 报价金额
   - 报价说明
   - 报告文件（可点击预览或下载）
4. 点击"接受报价"或"拒绝"按钮
   - 拒绝时需要填写拒绝原因

## 订单状态变化
- 待确认 → 接受后，订单状态变为"维修中"，实际价格更新为报价金额
- 待确认 → 拒绝后，订单状态保持不变，管理员可以重新报价

## API接口
- `PUT /api/admin/orders/:orderId/quote` - 管理员提交报价
- `PUT /api/orders/:orderId/accept-quote` - 用户接受报价
- `PUT /api/orders/:orderId/reject-quote` - 用户拒绝报价
- `POST /api/upload/quote` - 上传报价报告文件

## 注意事项
1. 报价功能仅对"维修中"状态的订单可用
2. 每个订单只能有一个待确认的报价
3. 接受报价后，订单的实际价格会被更新为报价金额
4. 拒绝报价后，管理员需要重新报价才能继续
