## 🎯 项目概述

维修业务管理系统是一个面向维修服务企业的全流程业务管理系统，涵盖从客户引流、订单管理、维修进度跟踪、支付结算到库存管理和数据分析的完整业务链条。系统采用前后端分离架构，提供Web管理后台和微信小程序双端操作界面。


## ✨ 核心功能

### 1. 基础管理
- 用户管理（CRUD、角色分配、部门管理）
- 角色管理（权限树配置）
- 权限管理（树形结构管理）
- 人员管理（员工档案）
- 单位管理（组织架构树）
- 日志管理（登录/操作/系统/错误日志）
- 参数管理（系统/业务/支付/消息参数）

### 2. 业务管理
- 免责协议管理
- 维修内容管理
- 绑定/解绑管理

### 3. 引流模块
- 成功案例管理（图片上传、案例展示、排序）
- 人工客服配置（客服信息、二维码、工作时间）
- 抖音获客管理（视频链接、文案、数据统计）
- 合作企业管理（企业信息、合作状态）

### 4. 维修业务
- 机械种类管理
- 机械名称管理
- 订单管理（小程序订单、手动创建订单）
- 检测报告管理（维修报价单、检测费用）
- 测试报告
- 维修报告
- 维修合同
- 维修提醒
- 联动维修
- 维修进度（进度申请、进度照片、进度视频）

### 5. 支付模块
- 转账支付管理
- 在线支付管理
- 发票管理

### 6. 进销存
- 配件管理
- 供应商管理

### 7. 查询统计
- 收入统计
- 开支统计
- 订单统计
- 超时统计
