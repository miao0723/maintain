第一章　引言

《众云信息科技维修回收综合服务平台V1.0》是一款面向维修服务企业的全流程数字化管理软件，支持 Web 管理后台与微信小程序（用户端 / 工程师端）双端协同。系统覆盖从客户引流、报修下单、维修作业、支付结算到库存管理与数据分析的完整业务链条，帮助企业实现服务过程可追溯、经营数据可量化。

本说明书用于说明软件的功能、架构、部署与操作方法，供著作权登记审查及最终用户参考。软件全称：众云信息科技维修回收综合服务平台V1.0；内部代号 CMMS（Computerized Maintenance Management System）。

第二章　总体概述

系统采用前后端分离架构：后端基于 ThinkPHP 8.1（PHP 8.1+）提供 RESTful API，数据层使用 MySQL 8.0 与 Redis 7.0；Web 管理后台基于 Vue 3 + Vite 5 + Element Plus 构建；微信小程序端提供扫码报修、进度查看与验收评价。AI 客服采用"路由智能体 + 领域智能体"的分层多智能体架构。

维度说明
适用对象家电 / 手机电脑 / 汽车等各类维修服务企业
用户角色超级管理员、后台管理员、工程师、普通客户
终端形态Web 管理后台（PC 浏览器）+ 微信小程序（用户端 / 工程师端）
部署形态Docker 容器化一键部署，亦支持传统 LAMP/WAMP 部署

第七章　接口设计

后端以 RESTful 风格暴露接口，统一返回 {code, message, data} 结构；主要接口分组：

分组示例端点说明
认证POST /api/auth/login登录获取 JWT，refresh 刷新令牌
用户/角色GET /api/users, /api/roles用户与角色权限管理
维修业务/api/orders, /api/repair/*订单与维修进度管理
支付/api/pay/*转账/在线支付与回调验签
AI 客服/api/chat/*多智能体对话接口
接口路径兼容 /api 与 /mp-api 双前缀；小程序通过 /mp-api 由 Nginx 反代至后端。

第八章　安全设计

  • 身份认证：JWT 无状态令牌鉴权，密码经 bcrypt 加盐哈希存储，杜绝明文。
  • 权限隔离：基于 RBAC 的角色权限校验，客户端与管理端逻辑隔离。
  • 密钥管理：数据库密码、微信 AppSecret、支付密钥等统一存放于 .env，源码零硬编码。
  • 传输安全：全程 HTTPS，Nginx 终止 TLS；支付回调报文经证书验签。
  • 文件安全：上传文件类型与大小受限，图片自动压缩，防范恶意文件。
  • 审计留痕：订单状态流转、报价、审批等关键操作全程记录，可追溯。

第十章　操作使用手册

10.1　管理员（Web 后台）

  1. 使用管理员账号登录 Web 管理后台；
  2. 在"基础管理"维护用户、角色与权限树；
  3. 在"维修业务"创建机械种类、录入订单、审核报价单与维修报告；
  4. 在"支付模块"核对转账/在线支付并开具发票；
  5. 在"查询统计"查看收入、开支、订单与超时报表。

10.2　客户（微信小程序）

  1. 扫码或搜索进入小程序，填写报修信息提交订单；
  2. 在"我的订单"查看维修进度照片/视频；
  3. 维修完成后进行验收与评价。

10.3　工程师（微信小程序）

  1. 接收派单，接单或拒单；
  2. 录入维修记录、上传现场照片/视频；
  3. 提交进度申请，等待客户验收。

第十一章　测试与验收

系统通过接口测试、业务流转测试与压力验证：

  • 认证接口：登录 / 刷新令牌 / 鉴权拦截全部通过；
  • 业务闭环：报修→派单→维修→验收→支付 全流程贯通；
  • 数据与缓存：MySQL 与 Redis 连接稳定，看板响应及时；
  • 健康检查：/health 与 /db-health 接口实时可用。
