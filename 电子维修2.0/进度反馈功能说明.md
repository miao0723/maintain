# 维修进度反馈功能说明

## 功能概述

为维修管理员提供上传维修进度反馈的功能，包括进度百分比、文字描述、图片和视频上传。用户可以在订单详情中查看维修进度和反馈记录。

## 数据库设计

### order_progress_updates 表（已存在）

```sql
CREATE TABLE `order_progress_updates` (
  `id` int NOT NULL AUTO_INCREMENT,
  `order_id` int NOT NULL,
  `technician_id` int NOT NULL COMMENT '维修人员ID',
  `progress` int NOT NULL COMMENT '进度百分比(0-100)',
  `description` text CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci NULL COMMENT '进度描述',
  `images` json NULL COMMENT '进度照片列表',
  `video_url` varchar(500) CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci NULL DEFAULT NULL COMMENT '视频URL',
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`) USING BTREE,
  INDEX `order_id`(`order_id` ASC) USING BTREE,
  INDEX `technician_id`(`technician_id` ASC) USING BTREE,
  INDEX `created`(`created_at` DESC) USING BTREE,
  CONSTRAINT `order_progress_updates_ibfk_1` FOREIGN KEY (`order_id`) REFERENCES `orders` (`id`) ON DELETE CASCADE ON UPDATE RESTRICT,
  CONSTRAINT `order_progress_updates_ibfk_2` FOREIGN KEY (`technician_id`) REFERENCES `users` (`id`) ON DELETE CASCADE ON UPDATE RESTRICT
) ENGINE = InnoDB AUTO_INCREMENT = 1 CHARACTER SET = utf8mb4 COLLATE utf8mb4_0900_ai_ci ROW_FORMAT = Dynamic;
```

## 后端 API

### 1. 获取订单进度反馈

**接口**: `GET /api/progress/:orderId`

**权限**: 订单所有者、分配的维修人员、管理员

**响应示例**:
```json
{
  "success": true,
  "data": {
    "orderId": 123,
    "progressUpdates": [
      {
        "id": 1,
        "order_id": 123,
        "technician_id": 5,
        "progress": 50,
        "description": "正在检测故障原因",
        "images": ["http://example.com/image1.jpg"],
        "video_url": "http://example.com/video.mp4",
        "created_at": "2026-05-23T10:30:00.000Z",
        "technician_name": "张维修师",
        "technician_avatar": "http://example.com/avatar.jpg"
      }
    ]
  }
}
```

### 2. 创建进度反馈

**接口**: `POST /api/progress/:orderId`

**请求体**:
```json
{
  "progress": 50,
  "description": "正在检测故障原因",
  "images": ["http://example.com/image1.jpg", "http://example.com/image2.jpg"],
  "videoUrl": "http://example.com/video.mp4"
}
```

**权限**: 分配的维修人员或管理员

### 3. 上传进度图片

**接口**: `POST /api/progress/:orderId/images`

**Content-Type**: `multipart/form-data`

**字段**: `images` (文件数组，最多9张)

**响应示例**:
```json
{
  "success": true,
  "message": "图片上传成功",
  "data": {
    "images": [
      "http://example.com/uploads/progress/123/1234567890_abc123.jpg",
      "http://example.com/uploads/progress/123/1234567891_def456.jpg"
    ]
  }
}
```

### 4. 上传进度视频

**接口**: `POST /api/progress/:orderId/video`

**Content-Type**: `multipart/form-data`

**字段**: `video` (视频文件，最大100MB)

**响应示例**:
```json
{
  "success": true,
  "message": "视频上传成功",
  "data": {
    "video_url": "http://example.com/uploads/progress/123/1234567890_abc123.mp4"
  }
}
```

### 5. 删除进度反馈

**接口**: `DELETE /api/progress/:orderId/:progressId`

**权限**: 创建者或超级管理员

## 前端页面

### 1. 进度反馈页面

**路径**: `pages/progress-feedback/progress-feedback`

**功能**:
- 进度百分比选择（滑块 + 快捷按钮）
- 文字描述输入
- 图片上传（支持拍照和选择，最多9张）
- 视频上传（支持拍摄和选择，最多1个）
- 历史反馈记录展示

**主要方法**:
- `chooseImage()`: 选择或拍摄图片
- `uploadImage()`: 上传单张图片
- `chooseVideoCamera()`: 拍摄视频
- `chooseVideoLibrary()`: 选择视频
- `uploadVideo()`: 上传视频
- `submitProgress()`: 提交进度反馈

### 2. 我的订单页面

**更新**: 在"处理中"状态的订单操作按钮中添加"📹 进度反馈"按钮

**方法**:
- `uploadProgress()`: 跳转到进度反馈页面

### 3. 订单详情页面

**更新**: 在维修进度卡片下方显示进度反馈记录

**功能**:
- 显示所有进度反馈记录
- 每条记录显示：进度百分比、时间、维修人员信息、描述、图片、视频
- 支持图片预览和视频播放

## 使用流程

### 维修人员操作流程

1. 进入"我的订单"页面
2. 找到"处理中"状态的订单
3. 点击"📹 进度反馈"按钮
4. 选择或设置当前进度百分比（可使用快捷按钮）
5. 填写进度描述（可选）
6. 上传进度照片（支持拍照或选择本地图片，最多9张）
7. 上传进度视频（支持拍摄或选择本地视频，可选）
8. 点击"提交进度"按钮
9. 系统自动更新订单进度并创建进度反馈记录

### 用户查看流程

1. 进入订单详情页面
2. 查看维修进度卡片
3. 查看进度反馈记录（如果有）
4. 点击图片可预览大图
5. 点击视频可直接播放

## 技术特点

1. **文件上传**: 使用 multer 中间件处理文件上传
2. **权限控制**: 只有订单分配的维修人员和管理员可以添加进度反馈
3. **文件组织**: 按订单ID组织上传目录，便于管理
4. **多媒体支持**: 同时支持图片和视频上传
5. **实时反馈**: 维修进度实时更新，用户可实时查看
6. **历史记录**: 完整保存所有进度反馈记录

## 注意事项

1. 视频上传限制为100MB，建议控制视频时长
2. 图片最多上传9张
3. 只能对"处理中"状态的订单添加进度反馈
4. 文件上传需要后端支持跨域和正确的路径配置
5. 建议在前端添加上传进度提示和错误处理
