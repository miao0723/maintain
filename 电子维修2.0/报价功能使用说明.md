# 管理员报价功能使用说明

## 功能概述
- 管理员可以给维修中的订单返回报价和维修报告
- 支持上传图片和文档文件（PDF、Word、Excel等）
- 用户可以查看报价详情、预览报告文件
- 用户可以接受或拒绝报价

## 数据库设置

### 1. 运行迁移SQL
```bash
mysql -u root -p repair < backend/database/migrations/20260425_add_order_quote_fields.sql
```

这会添加以下字段到`orders`表：
- `quote_price` - 报价金额
- `quote_description` - 报价说明
- `quote_files` - 报价报告文件（JSON格式）
- `quote_status` - 报价状态（pending/accepted/rejected）
- `quote_created_at` - 报价创建时间
- `quote_created_by` - 创建报价的管理员ID
- `quote_rejected_reason` - 用户拒绝的原因

## 管理员端操作

### 1. 提交报价
1. 进入"我的订单"页面
2. 找到"维修中"状态的订单
3. 点击"返回报价"按钮
4. 填写：
   - 报价金额（必填）
   - 报价说明（选填）
   - 上传报告文件（选填，最多5个）
5. 点击"提交报价"

### 2. 查看报价状态
在订单详情中会显示报价信息：
- 待确认：显示报价金额、说明和报告文件，可重新报价
- 已接受：显示已接受状态
- 已拒绝：显示拒绝原因

## 用户端操作

### 1. 查看报价
1. 进入"我的订单"页面
2. 点击订单进入详情页
3. 如果有报价，会显示在"报价信息"卡片中

### 2. 接受报价
1. 点击"接受报价"按钮
2. 确认后：
   - 订单状态变为"维修中"
   - 实际价格更新为报价金额
   - 管理员可以继续处理订单

### 3. 拒绝报价
1. 点击"拒绝"按钮
2. 填写拒绝原因（必填）
3. 确认后：
   - 报价状态变为"已拒绝"
   - 管理员可以重新报价

## 订单状态流转

```
待处理 (pending) → 维修中 (processing) [管理员接单/开始处理]
  ↓
待确认 (pending + quote_price) → 待确认 (quote_status='pending') [管理员提交报价]
  ↓
待确认 → 已接受 (quote_status='accepted') [用户接受]
↓
待确认 → 已拒绝 (quote_status='rejected') [用户拒绝]
  ↓
已拒绝 → 待确认 (quote_status='pending') [管理员重新报价]
```

## 注意事项
1. 只有"维修中"状态的订单可以返回报价
2. 每个订单同时只能有一个待确认的报价
3. 接受报价后，实际价格会更新为报价金额
4. 拒绝报价后，管理员可以重新报价
5. 支持的文件格式：jpg, png, gif, webp, pdf, doc, docx, xls, xlsx, txt
6. 单个文件最大10MB，总共最多5个文件

## API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/admin/orders/:id/quote` | PUT | 管理员提交报价 |
| `/api/orders/:id/accept-quote` | PUT | 用户接受报价 |
| `/api/orders/:id/reject-quote` | PUT | 用户拒绝报价 |
| `/api/upload/quote` | POST | 上传报价文件 |
