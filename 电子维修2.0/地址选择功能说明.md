# 地址选择功能测试说明

## 功能概述
在维修总流程中，当用户选择"上门取件"服务方式时，现在可以选择用户在"我的"页面地址管理中保存的地址。

## 功能特性

### 1. 服务方式选择
- 用户可以选择"到店维修"或"上门取件"两种服务方式
- 当选择"上门取件"时，会自动弹出地址选择提示

### 2. 地址选择器
- 显示用户在地址管理中保存的所有地址
- 支持从列表中选择已有地址
- 支持添加新地址（跳转到地址管理页面）
- 选中地址后会显示勾选标识

### 3. 已选地址显示
- 选中地址后，在页面上显示详细的地址信息
- 包括联系人姓名、电话、省市区和详细地址
- 可以点击更换地址

### 4. 地址列表刷新
- 从地址管理页面返回时，自动刷新地址列表
- 添加或编辑地址后，维修页面的地址列表会自动更新

### 5. 订单提交验证
- 如果选择"上门取件"但没有选择地址，会提示用户选择地址
- 提交订单时，地址信息会包含在订单数据中

## 使用流程

1. **选择设备和服务**
   - 选择设备类型、品牌、型号
   - 选择故障问题

2. **选择服务方式**
   - 点击"上门取件"服务方式
   - 自动弹出地址选择器

3. **选择或添加地址**
   - 从列表中选择已有地址
   - 或点击"添加新地址"跳转到地址管理页面

4. **查看已选地址**
   - 选中的地址会显示在页面上
   - 包含联系人信息和详细地址

5. **提交订单**
   - 点击提交维修订单
   - 地址信息会包含在订单中

## 测试步骤

### 测试1：已有地址的情况
1. 进入"我的"页面 → "地址管理"
2. 确保至少有一个地址
3. 进入"维修服务"页面
4. 选择设备、品牌、型号、故障问题
5. 选择"上门取件"服务方式
6. 从地址列表中选择一个地址
7. 查看地址是否正确显示
8. 提交订单，检查订单数据是否包含地址信息

### 测试2：没有地址的情况
1. 进入"我的"页面 → "地址管理"
2. 删除所有地址
3. 进入"维修服务"页面
4. 选择设备、品牌、型号、故障问题
5. 选择"上门取件"服务方式
6. 应该提示"您还没有添加地址，是否现在去添加？"
7. 点击"去添加"，跳转到地址管理页面
8. 添加一个新地址
9. 返回维修页面，地址列表应该刷新
10. 可以选择新添加的地址

### 测试3：更换地址
1. 选择一个地址后，再次点击地址显示区域
2. 地址选择器应该弹出
3. 选择另一个地址
4. 地址信息应该更新

### 测试4：切换服务方式
1. 选择"上门取件"并选择地址
2. 切换到"到店维修"
3. 地址选择区域应该隐藏
4. 再次切换回"上门取件"
5. 之前选择的地址应该保留

## 技术实现

### 修改的文件
1. `pages/repair/repair.js` - 添加地址选择相关逻辑
2. `pages/repair/repair.wxml` - 添加地址选择器UI
3. `pages/repair/repair.wxss` - 添加地址选择器样式
4. `pages/address-edit/address-edit.js` - 添加返回刷新逻辑
5. `pages/address/address.js` - 添加页面卸载刷新逻辑

### 数据结构
订单数据中的地址字段格式：
```javascript
{
  contactName: "张三",
  contactPhone: "13800138000",
  province: "广东省",
  city: "深圳市",
  district: "南山区",
  detail: "科技园南区XXX大厦"
}
```

## 注意事项

1. 地址数据从后端API获取，如果API失败会回退到本地存储
2. 地址选择器采用底部弹窗设计，体验更流畅
3. 用户必须登录才能使用地址选择功能
4. 提交订单时，如果选择了"上门取件"但没有选择地址，会阻止提交并提示用户
5. 地址列表会在页面显示时自动刷新，确保数据最新
