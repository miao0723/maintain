# 图片资源说明

本文件夹需要放置以下图片资源：

## 必需图片

### 1. logo.png (推荐尺寸: 200x200px)
- 用途: 免责协议页和登录页的Logo
- 建议格式: PNG（支持透明背景）
- 放置位置: 项目根目录的 `images/logo.png`

## 可选图片（如果需要底部导航栏）

如果需要启用底部导航栏，请在 app.json 中取消 tabBar 配置，并准备以下图片：

### 2. 底部导航图标 (推荐尺寸: 81x81px)
- `home.png` - 首页图标（未选中状态）
- `home-active.png` - 首页图标（选中状态）
- `log.png` - 记录图标（未选中状态）
- `log-active.png` - 记录图标（选中状态）

## 快速解决方案

### 方案1: 使用在线图标
你可以从以下网站下载免费图标：
- Iconfont (阿里图标库): https://www.iconfont.cn/
- Font Awesome: https://fontawesome.com/

### 方案2: 暂时使用文字替代
当前代码已经配置为可以在没有图标的情况下正常运行。

## 注意事项
1. 图片文件名必须与代码中引用的文件名完全一致（区分大小写）
2. 建议使用 PNG 格式，支持透明背景
3. 图标尺寸建议为 81x81px（@2x）或 162x162px（@3x）
4. Logo图片建议使用正方形，最大不超过 500KB
