# CMMS Backend - 部署检查清单

本文档提供CMMS后端API系统的部署前和部署后检查清单，确保系统可以安全、稳定地投入生产环境。

## 📋 部署前检查

### 环境要求

- [ ] **PHP 版本**: PHP 8.1 或更高版本
- [ ] **数据库**: MySQL 5.7+ 或 MariaDB 10.3+
- [ ] **Redis**: Redis 5.0+ (用于缓存和会话)
- [ ] **Web服务器**: Nginx 1.18+ 或 Apache 2.4+
- [ ] **Composer**: 已安装并可访问
- [ ] **磁盘空间**: 至少 500MB 可用空间

### 配置文件

- [ ] **环境配置**: `.env` 文件已从 `.env.example` 复制并配置
- [ ] **数据库配置**: 数据库连接信息正确（host, port, database, username, password）
- [ ] **Redis配置**: Redis连接信息正确
- [ ] **JWT密钥**: JWT_SECRET 已设置为强随机字符串（至少32位）
- [ ] **调试模式**: 生产环境 APP_DEBUG 设置为 false
- [ ] **CORS配置**: 允许的域名已正确配置

### 安全检查

- [ ] **JWT密钥**: 已更改默认JWT密钥
- [ ] **数据库密码**: 使用强密码，未使用默认值
- [ ] **Redis密码**: 生产环境Redis已设置密码
- [ ] **文件权限**: 敏感文件权限正确（.env 600, 目录 755）
- [ ] **HTTPS**: 生产环境已配置SSL证书
- [ ] **防火墙**: 仅开放必要端口（80, 443, 22）

### 数据库准备

- [ ] **数据库创建**: 已创建空数据库
- [ ] **用户权限**: 数据库用户已创建并授予适当权限
- [ ] **字符集**: 数据库字符集为 utf8mb4
- [ ] **备份**: 生产环境有数据库备份计划

### 1. 代码部署

- [ ] **代码上传**: 代码已上传到服务器

## 🔄 常见问题排查

### 服务无法启动

1. 检查PHP版本: `php -v`
2. 检查扩展: `php -m`
3. 检查端口占用: `netstat -tlnp | grep :80`
4. 检查错误日志: `tail -f runtime/log/error.log`

### 数据库连接失败

1. 检查数据库服务: `systemctl status mysql`
2. 测试连接: `mysql -h host -u user -p`
3. 检查防火墙: 确保数据库端口可访问
4. 验证配置: 检查 .env 中的数据库配置

### API返回500错误

1. 查看PHP错误日志
2. 检查文件权限
3. 验证数据库连接
4. 检查PHP扩展是否完整

### 认证失败

1. 验证JWT配置
2. 检查token有效期
3. 验证中间件配置
4. 检查Redis连接
